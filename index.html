03 / APRENDIZAJE

Competencias Adquiridas

Selecciona cada botón para consultar cómo se aplica la competencia en las prácticas de la Unidad I.

01

Estructura semántica con HTML5

Organicé el contenido usando etiquetas como header, nav, main, section y footer. Esto facilita comprender y mantener la estructura de la página.

02

Diseño visual y responsivo con CSS3

Usé estilos, espaciado, contraste, Flexbox y CSS Grid para presentar la información en tarjetas y adaptar el diseño a pantallas de distintos tamaños.

03

Interactividad con JavaScript y DOM

Seleccioné elementos del documento y escuché eventos de clic para mostrar u ocultar información de manera accesible, actualizando el estado del botón y el contenido asociado.

04

Control de versiones con Git y GitHub

Practiqué el flujo de trabajo con ramas y commits descriptivos para registrar avances, revisar cambios y preparar la integración del proyecto en la rama principal.
