# Recuperación de Aplicaciones Web

## Creación del repositorio

Este repositorio fue creado en GitHub con la finalidad de almacenar y organizar los archivos correspondientes a la recuperación de la asignatura Aplicaciones Web de la Unidad I.

El repositorio permite administrar el código fuente del proyecto, mantener un registro de los cambios realizados y organizar el trabajo mediante el uso de ramas.

## Objetivo

Contar con un espacio de trabajo en línea para desarrollar, guardar y administrar los archivos del proyecto, utilizando Git y GitHub como herramientas de control de versiones.

## Organización del repositorio

- **`main`:** rama principal del repositorio.
- **`Recuperacion_U1`:** rama destinada al desarrollo y almacenamiento de los archivos correspondientes a la recuperación de la Unidad I.
- **`README.md`:** archivo que describe el propósito y la organización del repositorio.

## Herramientas utilizadas

- **Git:** sistema de control de versiones.
- **GitHub:** plataforma para alojar el repositorio y administrar los archivos del proyecto.
