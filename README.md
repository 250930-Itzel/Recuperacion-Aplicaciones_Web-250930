## Descripción

Portafolio académico creado para la actividad de recuperación de la Unidad I. Integra una presentación personal, tres tarjetas de niveles educativos previos, un banner con efecto parallax y una sección de cuatro competencias con detalles expandibles mediante JavaScript.

## Tecnologías

- **HTML5:** estructura semántica, navegación por anclas y contenido.
- **CSS3:** diseño adaptable con Grid/Flexbox, contraste, foco visible y alternativa móvil para el parallax.
- **JavaScript:** menú móvil, controles accesibles para expandir/contraer competencias y año del pie de página.
- **Git y GitHub:** rama de trabajo y commits descriptivos.
- **GitHub Pages:** publicación estática (pendiente de confirmar desde Settings → Pages).

## Personalización necesaria antes de entregar

Las tarjetas educativas incluyen textos de ejemplo. Sustituye “Nombre de tu…” y “Agregar…” por los datos reales de primaria, secundaria y bachillerato, incluidos periodos y localidad. No publiques información personal que prefieras mantener privada.

## Pruebas que deben realizarse

Marca cada punto únicamente después de comprobarlo en el navegador:

- [ ] La navegación lleva a las secciones correctas.
- [ ] Las tres tarjetas educativas aparecen y muestran información real.
- [ ] El fondo parallax se percibe en escritorio y se desactiva en pantallas pequeñas.
- [ ] Los cuatro botones de competencias expanden y contraen sus detalles.
- [ ] El menú móvil abre, cierra y navega correctamente.
- [ ] No hay recursos rotos ni errores en la consola del navegador.
- [ ] La página se revisó en escritorio y móvil.
- [ ] La versión publicada de GitHub Pages muestra los cambios.

## Publicación con GitHub Pages

1. Abre **Settings → Pages** en el repositorio.
2. En **Build and deployment**, elige **Deploy from a branch**.
3. Selecciona la rama `main` y la carpeta `/(root)`; guarda los cambios.
4. Después de que termine el despliegue, abre la URL que GitHub Pages muestra y prueba la página publicada.

La configuración de Pages y la publicación final deben verificarse en la cuenta de GitHub; no se afirma aquí que ya estén activadas.
